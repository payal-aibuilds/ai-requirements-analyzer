# AI Requirements Analyzer

An AI-powered application that transforms unstructured business requirements into structured product and technical specifications.

## Objective

The goal of this project is to demonstrate how AI can assist Business Analysts, Product Owners, and consultants in converting ambiguous business needs into actionable requirements.

## Planned capabilities

- Analyze unstructured business requirements
- Identify the underlying business problem
- Generate functional requirements
- Generate non-functional requirements
- Create user stories
- Generate acceptance criteria
- Suggest a high-level technical architecture
- Identify risks and assumptions

## Tech Stack

- Python
- FastAPI
- LLM API
- Git
- GitHub
